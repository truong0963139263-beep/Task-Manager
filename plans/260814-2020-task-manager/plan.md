## Overview

## Tech Stack
- **Frontend:** HTML5, Vanilla CSS (Design Tokens, CSS Grid/Flexbox, Glassmorphism, CSS Variables)
- **Logic & State:** JavaScript ES6+ (Modular JS / ES Modules)
- **Persistence:** Browser LocalStorage API
- **Fonts & Icons:** Google Fonts (Inter/Outfit), FontAwesome SVG Icons
